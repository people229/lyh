Web 前端的长度单位

CSS 中的长度单位分为绝对单位和相对单位。绝对单位有固定的物理长度， 相对单位则依赖参照物（父元素、根元素或视口），是响应式布局的基础。

浏览器标准：1in = 96px。屏幕上的物理单位（cm、mm、pt）由浏览器按此标准换算，可能存在微小误差。

一、绝对单位（Absolute Units）

px

像素。屏幕上最小的显示单位，最常用，不随环境变化。

示例：width: 96px
in

英寸。1in = 96px = 2.54cm，常用于打印场景。

示例：width: 1in（96px）
cm

厘米。1cm ≈ 37.8px，屏幕显示为近似值。

示例：width: 2.54cm（≈96px）
mm

毫米。1mm ≈ 3.78px，1cm = 10mm。

示例：width: 25.4mm（≈96px）
pt

磅（点）。印刷常用，1pt = 1/72 in ≈ 1.33px。

示例：width: 72pt（=96px）
pc

派卡。1pc = 12pt = 16px，源于活字印刷。

示例：width: 6pc（=96px）

直观对比：下列六个盒子宽度完全相等（均为 96px）

width: 96px
width: 1in
width: 2.54cm
width: 25.4mm
width: 72pt
width: 6pc

二、相对单位（Relative Units）

%

相对父元素的尺寸。宽度百分比基于父宽，高度百分比基于父高。

示例：width: 50%（父元素的一半）
em

相对当前元素的 font-size。元素嵌套时会层层叠加计算。

示例：width: 8em（随字体放大）
rem

相对根元素（html）的 font-size，默认 16px，不随父级叠加。

示例：width: 12rem（16px × 12）
ex

相对当前字体小写字母 x 的高度，适合按字高排版。

示例：width: 10ex
ch

相对数字“0”的宽度，适合控制每行字符数。

示例：width: 10ch
% / auto

流式布局中配合 % 使用，可实现随窗口伸缩的弹性盒子。

示例：width: 75%
vw

视口（viewport）宽度的 1%，100vw = 视口总宽。

示例：width: 30vw
vh

视口高度的 1%，100vh = 视口总高，常用于整屏布局。

演示见下方 vh 盒子
vmin / vmax

vmin 取 vw/vh 中较小者，vmax 取较大者，适配横竖屏。

示例：width: 20vmin

三、em 与 rem 的区别

em：相对父元素字体大小

父元素 font-size: 24px 子盒子 width: 8em = 24px × 8 = 192px
width: 8em（≈192px）

rem：相对根元素字体大小

同样的父元素 font-size: 24px 子盒子 width: 12rem = 16px × 12 = 192px
width: 12rem（192px，与父级字体无关）

五、常用换算表

单位 类别 换算关系
px 绝对 1in = 96px（基准单位）
pt 绝对 1pt = 1/72 in ≈ 1.33px
pc 绝对 1pc = 12pt = 16px
cm / mm 绝对 1cm ≈ 37.8px，1mm ≈ 3.78px
em / rem 相对 em 相对当前/父级字体，rem 相对根字体（默认 16px）
vw / vh 相对 分别为视口宽、高的 1%
vmin / vmax 相对 vw 与 vh 的较小值 / 较大值
ex / ch 相对 相对字形 x 高度 / 数字 0 的宽度
