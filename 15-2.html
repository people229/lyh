条件 1if-else 双分支 / 多分支

输入一个 0~100 的分数，程序按多分支判断输出等级：≥90 优秀，≥80 良好，≥60 及格，否则不及格。

// if - else if - else 多分支 if (lyh_score >= 90) { lyh_grade = "优秀"; } else if (lyh_score >= 80) { lyh_grade = "良好"; } else if (lyh_score >= 60) { lyh_grade = "及格"; } else { lyh_grade = "不及格"; }

条件 2switch 多值匹配

switch 适合对一个变量的多个离散取值做精确匹配，break 防止 case 穿透。

switch (lyh_day) { case 1: lyh_name = "星期一"; break; case 2: lyh_name = "星期二"; break; ... default: lyh_name = "输入有误"; }

循环for / while / do-while 三种循环

for 适合已知次数；while 先判断后执行；do-while 先执行一次再判断（至少执行 1 次）。

// for：1~100 累加 for (var lyh_i = 1; lyh_i <= 100; lyh_i++) { lyh_sum += lyh_i; } // while：先判断后执行 while (lyh_n <= 5) { lyh_n++; } // do-while：先执行一次再判断 do { lyh_m++; } while (lyh_m < 5);
