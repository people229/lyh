Lucide 图标（SVG 方式）

Lucide 是基于 Feather Icons 的开源图标库，以“SVG 方式”使用： 通过 data-lucide 属性声明图标名，脚本会把元素替换为内联 <svg>， 再像普通 SVG 一样用 CSS 控制颜色、尺寸和动画。

用法要点：引入 cdn/lucide.min.js，在元素上写 <i data-lucide="home"></i>，最后调用 lucide.createIcons()。生成的 <svg> 默认继承 currentColor，用 color 即可改色。

五、用法速查表

属性 / 方法 作用 说明
data-lucide="名称" 声明图标 图标名为小写短横线命名，如 shopping-cart
lucide.createIcons() 渲染图标 扫描 DOM 并把占位元素替换为内联 SVG
width / height 尺寸 设置 SVG 的宽高，默认 24×24
color 颜色 SVG 使用 currentColor 描边
stroke-width 线条粗细 默认 2，可设为 1–4
class 附加样式 可叠加任意 CSS 类与动画
