JavaScript 六种基本数据类型

Number · String · Boolean · Null · Undefined · Object — 点击每张卡片的按钮查看 typeof 结果

1 / 6 Number 数值

包括整数、浮点数、科学计数、Infinity、NaN。

// 各种数字 var lyh_int = 100; var lyh_float = 3.14; var lyh_big = 1.23e6;
2 / 6 String 字符串

用单引号、双引号或反引号包裹的文本序列。

// 字符串的三种写法 var lyh_s1 = 'hello'; var lyh_s2 = "world"; var lyh_s3 = `模板字符串`;
3 / 6 Boolean 布尔

只有两个值：true（真）和 false（假）。

var lyh_ok = true; var lyh_no = false; // 关系运算返回布尔 var lyh_cmp = (5 > 3);
4 / 6 Null 空值

表示"没有对象"。注意：typeof null === 'object'（历史遗留 bug）。

var lyh_nothing = null; // 空值也是一个关键字
5 / 6 Undefined 未定义

变量声明后未赋值、或访问不存在的属性时得到的值。

var lyh_x; // 声明未赋值 var lyh_y = lyh_x; // y 也是 undefined
6 / 6 Object 对象

引用类型，包括普通对象、数组、函数、Date 等。

var lyh_obj = {name: '梁月虹'}; var lyh_arr = [1, 2, 3]; var lyh_fn = function(){};
